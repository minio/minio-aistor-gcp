===================================================================================
DEPLOYMENT STATUS
===================================================================================

Monitor the deployment:

1. Check Operator status:
   kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/name=aistor-objectstore-operator

2. Check ObjectStore CRD:
   kubectl get objectstore -n {{ .Release.Namespace }}

3. Check MinIO pods:
   kubectl get pods -n {{ .Release.Namespace }} -l app={{ .Release.Name }}-store

===================================================================================
ACCESSING MINIO AISTOR
===================================================================================

Once deployment is complete:

1. Get your MinIO root credentials:

   kubectl get secret {{ .Release.Name }}-env-config \
     -n {{ .Release.Namespace }} \
     -o jsonpath='{.data.config\.env}' | base64 -d

2. Access MinIO Console (Web UI):

   Wait for LoadBalancer IP:
   kubectl get svc -n {{ .Release.Namespace }} -l v1.min.io/console={{ .Release.Name }}-store

   Access via: http://<EXTERNAL-IP>:9001

3. Access MinIO API (S3 endpoint):

   Wait for LoadBalancer IP:
   kubectl get svc -n {{ .Release.Namespace }} -l v1.min.io/tenant={{ .Release.Name }}-store

   S3 Endpoint: http://<EXTERNAL-IP>:9000

===================================================================================
USING MINIO CLIENT (mc)
===================================================================================

Install MinIO Client:
  wget https://dl.min.io/client/mc/release/linux-amd64/mc
  chmod +x mc && sudo mv mc /usr/local/bin/

Configure mc alias:
  mc alias set myaistor http://<ENDPOINT>:9000 <ACCESS-KEY> <SECRET-KEY>

Test connection:
  mc admin info myaistor
